# Danyzaa Cafe

Danyzaa Cafe is an interactive and responsive cafe website built using HTML5, CSS3, Bootstrap 5, and JavaScript DOM.

## About the Project

Danyzaa Cafe is a modern cafe website designed to provide users with an attractive and interactive browsing experience. The website includes a responsive layout, interactive menu, search and category filtering, shopping cart functionality, special offers, blog section, and reservation form.

## Key Functionalities

### Interactive Menu

Users can search for menu items and filter them by category:

- Breakfast
- Main Course
- Desserts
- Drinks

### Shopping Cart

Users can:

- Add items to the cart
- Navigate to the cart using the Go to Cart button
- Increase item quantity
- Decrease item quantity
- Remove items from the cart
- View the total number of items
- View the total price
- See an empty cart message

When an item is removed from the cart, its menu button automatically changes back to Add to Cart.

### Special Offers

The Special Offers section uses Bootstrap cards, badges, buttons, and modal components to display offer information.

Users can view offer details and navigate to the reservation section.

### Reservation

The website includes a reservation form built using Bootstrap form components.
